# Windows Troubleshooting Lab

## Overview

This project documents hands-on Windows troubleshooting exercises using built-in Windows tools and PowerShell.

The goal is to develop practical skills in Windows system administration, diagnostics, and problem-solving.

## Objectives

- Learn to investigate common Windows system issues.
- Explore built-in Windows diagnostic tools.
- Use PowerShell to collect and inspect system information.
- Document troubleshooting steps and findings.
- Practice verifying results after applying a solution.

## Environment

- Operating System: Windows
- Shell: PowerShell
- Documentation: Markdown
- Version Control: Git and GitHub
